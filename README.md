# Belisario Experiences — prototipo

Prototipo web estático y responsive para presentar una propuesta de plataforma de descubrimiento de experiencias de Grupo Belisario.

## Incluye
- Página de inicio con estética editorial premium.
- Sección Explorar con filtros interactivos.
- Tarjetas de experiencias con ventanas modales.
- Flujo simulado para continuar a reservas (no conecta con sistemas reales).
- Diseño adaptable a móvil y escritorio.
- Sin backend, dependencias de instalación ni base de datos.

## Cómo verlo
Abre `index.html` en tu navegador.

## Publicarlo en GitHub Pages
1. Crea un repositorio nuevo en GitHub.
2. Sube `index.html` y `README.md` a la raíz del repositorio.
3. Entra a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`, y guarda.
6. Espera a que GitHub Pages genere el enlace.

## Nota académica
Este es un prototipo conceptual. Los textos de las marcas, las categorías y los canales de reserva deben validarse con información oficial. Los botones de reserva solo muestran un aviso y no realizan reservas reales. Las imágenes se cargan desde Unsplash y las tipografías desde Google Fonts; se necesita conexión a internet para cargarlas.
